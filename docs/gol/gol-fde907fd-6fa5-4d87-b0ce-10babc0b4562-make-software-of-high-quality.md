# Make Software of High Quality

The project must make software with a high quality level for each ISO/IEC 25010 characteristic.

## Description

The repository is a template for new projects. Quality problems in the template occur again in each project that uses it. Each quality target must have a measure and a gate that examines it.

## More Information

ISO/IEC 25030 gives the template for quality requirements. ISO/IEC 25023 gives the measures.
