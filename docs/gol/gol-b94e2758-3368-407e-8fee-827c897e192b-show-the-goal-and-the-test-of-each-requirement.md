# Show the Goal and the Test of Each Requirement

Each requirement must have a verification case record and a link to a goal. The project must show which items give the function in the requirement.

## Description

A reader must see that the system does the functions in the requirements. A script examines the links in CI. A pull request cannot merge if a link is missing, if a link has no target, or if a requirement has no test.
