# docs

The specmgr documents of the project, one folder for each type: `dec` (decisions), `gol` (goals), `prb` (problem statements), `qa` (questions and answers), `req` (requirements), `rsk` (risks), `sop` (procedures) and `txt` (free text). The Engineering Handbook in `txt/` is the index.

Change a document with the specmgr tools, and do not change the front matter by hand.
