# STE Limits the Words for Software Specifications

## Cause

ASD-STE100 has a small list of approved words. Terms of software are not in the list.

## Trigger

Authors write requirements and policies about software in STE.

## Consequence

Authors use much time to write sentences again. Some texts become less clear. Authors can stop the STE check.

## Scope

- All specmgr documents

### Impact 3

## Strategy
